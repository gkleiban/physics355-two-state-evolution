# Physics 355 — Two-state time evolution

Interactive browser simulation for Formalism Lesson 11 (infinite square well): equal superposition of \(n=1\) and \(n=2\), with animated probability density, stripped \(\mathrm{Re}/\mathrm{Im}\,\Psi\), coefficient phasors, and frozen energy readouts.

**Live demo:** https://gkleiban.github.io/physics355-two-state-evolution/

Open `index.html` locally in any browser — no install, no CDN.
